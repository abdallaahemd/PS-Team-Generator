# 🎮 PS Team Generator

A modern gaming-style web app that randomly generates PlayStation multiplayer teams with chaotic Arabic team names and smooth animated UI.

Built using pure HTML, CSS, and Vanilla JavaScript with a responsive dark-mode gaming design inspired by modern esports interfaces.

## ✨ Features

* Randomly generates teams of 2 players
* Handles odd player counts automatically
* Dynamic player selection system
* Add custom player names instantly
* Random Arabic team names for every squad
* Smooth animations and loading effects
* Modern glassmorphism gaming UI
* Fully responsive for mobile & desktop
* Neon glow effects and interactive cards
* Fair randomization algorithm
* Clean and lightweight implementation

## 🎨 Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript

## 📱 Design Style

* Dark gaming theme
* Neon blue / purple accents
* Glassmorphism cards
* Smooth transitions & hover animations
* Mobile-first responsive layout

## 🚀 Purpose

This project was built for fun gaming sessions with friends to quickly create random balanced multiplayer teams in a stylish and interactive way.
